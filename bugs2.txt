sim.c (lines 17-35) – premature termination with n_to_eat
ft_exec_more_actions sets the shared dead flag (ft_set_dead_m(philo_d, 1)) as soon as the current philosopher reaches n_to_eat. Because every node’s dead pointer (wired in philosophers.c (lines 66-69)) refers to the same integer, the first philosopher who finishes his quota kills the entire simulation. You can see it by running ./philo 3 600 200 200 2: philosopher #1 eats twice, the flag flips, and the program exits while philosophers 2 and 3 have eaten only once. The intended behaviour is to stop only after each philosopher has eaten n_to_eat times, which requires tracking per-philosopher meal counts or a shared counter, not a single boolean.

timeft.c (lines 18-41) – wrong sleep duration units
The helper takes millisecond arguments (t_to_sleep, t_to_eat, etc. are parsed as ms) but passes them straight to usleep, which expects microseconds. For ms <= 200 the function calls usleep(ms) (e.g. ms=200 → usleep(200) = 0.2 ms) and returns immediately, so those phases are ~1000× shorter than requested and the “time to die” math becomes meaningless. For larger values it busy-loops with usleep(100) (0.1 ms) steps, again treating milliseconds as microseconds. This breaks the timing guarantees of the assignment and is why the sample run shows hundreds of actions happening within only a few milliseconds. Multiply by 1000 before calling usleep, and keep looping until the elapsed milliseconds reach the target.

philosophers.c (lines 47-88) – leaked fork array on printer allocation failure
When ft_set_philo can’t allocate the printer mutex it calls ft_free_list(start) and returns 0, but the forks array passed in is never freed. At that point every node’s forks field is still NULL (the assignment happens later in the loop), so ft_free_list can’t release the memory, and ft_init_list simply propagates NULL upwards. Subsequent retries will leak another n_philos * sizeof(pthread_mutex_t) block each time the printer allocation fails. Free forks before returning and/or make sure ft_free_list can release it even when the nodes were not wired yet.
